# sync-python

Python 数据采集与同步服务。负责人：**Python 负责人**。

## 职责

- 从约定的数据来源读取作品数据，完成校验、清洗与字段转换。
- 经 Java 的**内部导入接口**提交数据，具备有限重试、失败记录与安全重跑能力。
- 记录批次结果，使坏记录可定位、可重提。

## 边界

- **不直接写业务数据库**，全部通过内部导入接口提交。
- 不要求客户端为来源异常修改业务逻辑；来源不可用时保留上一次成功入库的数据。
- 缺失字段按"来源未提供"处理，不填 0 分、不造占位值。
