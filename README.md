# Otaku Data Platform

> 面向**尚无客户端的独立网站**：以一次授权接入已建成的通用客户端底座，在显著短于自建或采购的周期内，上线属于网站自己的客户端。
>
> **首站 Otaku 已接入，端到端闭环已打通并通过验收；当前重心在体验纵深、数据完整度与可运维性。**
>

> 产品定位（技术判断的上位依据）见 [`docs/product-positioning.md`](docs/product-positioning.md)。
> 进度与分工见 [`docs/ROADMAP.md`](docs/ROADMAP.md)。

## 1. 项目定位

本项目不是建设一个通用的 ACGN 数据服务平台，而是建设一套**面向多个独立网站的跨平台适配与客户端解决方案**。

核心目标：

1. 帮助独立网站适配不同客户端平台，包括 Android 与桌面端（当前已打通的形态）。
2. 让**尚无客户端**的网站，通过**一次授权**获得属于自己的客户端能力：网站侧无需承担开发工作，上线周期显著短于自建团队开发或采购外包。
3. 各网站保持独立运营，保留各自的品牌、业务逻辑和用户数据边界。

Otaku 是第一个接入对象，但继续独立运营：不合并网站、不以迁移 Otaku 全部业务为目标，也不默认共享不同网站的账号、收藏、浏览历史等用户数据。客户端是接入网站的客户端，用户是网站的用户——网站已有用户时，客户端应优先使用网站账号登录。

**产品原则（客户端与网站协作）**：优先通过客户端提供统一、便捷的使用体验，在需要使用网站原有页面或功能时，保留与对应原页的关联；不以封闭用户或替代网站为目标。

## 3. 第一阶段（已通过验收）

第一阶段以打通一个**可验收的最小闭环**为目标，现已完成：

- **双端真实浏览**：Android 与 Windows 桌面用真实接口完成列表 / 分页 / 搜索 / 详情；
- **同账号跨端管理**：同一账号双端登录，收藏与观看状态同步（LWW 冲突处理）；
- **可靠性与交付**：幂等、可重试、可观测、可独立启动（clean-room 演练 3.9s 启动）；
- **网站原页关联**：作品详情可跳转回对应网站的人读页（仅导航、不抓取、不自行拼接地址）；
- **站主运营后台**（A4）：站点可管理自己的用户与同步状态；
- **UGC 平台代存**（A 模式可选增值）：评论 / 审核 / 举报 / 导出 / 回复 / 编辑 / 点评等后端能力已上线。

第一阶段不依赖多站点。关于多站点的抽象，现阶段**决定不做**——只服务首站，已有结构留作接口、不为想象中的第二站写代码（依据见 [`docs/open-decisions.md`](docs/open-decisions.md) C7）。

## 4. 协作原则

### 4.1 自主实现
各模块负责人自主安排模块内部的设计、编码、目录结构、开发工具和实现步骤。本 README 只规定项目共同目标、技术边界和协作要求，不限制成员在自己负责的模块内作出合理的技术决策。

**自由度**：模块负责人**自己决定即可推进，不需要他人确认**——不需要负责人批准，也不需要其他模块同意。
负责人只给产品与商业层面的要求，**不给实现方案、不指定技术条目、不替模块决定它该做什么**。

### 4.2 接口协商
不同模块需要协作时，相关负责人应共同明确必要的接口约定，包括数据字段、请求与响应格式，以及必要的错误处理规则。接口一旦被其他模块依赖，涉及变更时应及时通知相关成员，避免各自按照不同约定开发。

### 4.3 及时同步
开发过程中遇到跨模块依赖、接口冲突或影响整体进度的问题，应及时与相关成员沟通。完成可供其他模块调用的功能后，应提供必要的使用方式、验证结果或联调信息。

### 4.4 尊重独立网站边界
对接 Otaku 或其他网站时，应明确需要复用的能力和数据范围。不得默认需要合并网站、迁移全部业务或共享用户数据。

### 4.5 数据合规
使用外部数据源时，应遵守相关使用条款、访问限制及适用法律法规。不要将密钥、密码等敏感凭据提交到公开仓库。

### 4.6 协作文件边界
不擅自删改其他协作者提交或负责的文件。如确需变更涉及他人模块的接口、数据结构或相关文件，应事先与相关协作者协商一致。

### 4.7 以仓库为协作依据
团队的现状以仓库中的文档、Issues 与 Projects 状态为准，不依赖线下口头同步。任何结论、接口约定与任务进度都应及时写回仓库，便于成员直接通过仓库判断现状。

第一阶段闭环已达成，当前工作分散在六条工作流，由各模块负责人自主推进（目标、拆解、顺序与验收自定）：

## 7. 仓库结构

```text
app-client/       Flutter 客户端（Android + Windows 桌面）
backend-java/     Java 业务后端（Spring Boot）
```
