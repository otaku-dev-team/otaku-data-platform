| # | 检查项 | 通过标准 |

### 6.3 验收中发现并已修复的缺陷

| 缺陷 | 现象 | 修复 |
| --- | --- | --- |
| 封面三态混淆 | 「无封面」「加载中」「加载失败」共用同一灰底图标，用户分不清是在加载还是真没有 | 拆成三态；加载失败按 6.3 回退占位（PR #28） |
| 切换筛选不回顶 | 从长列表切到短列表仍停在旧偏移，看起来像跳页 | 换条件时重置滚动位置，从详情返回不受影响（PR #28） |
| 换条件失败静默展示旧数据 | 断网时点「漫画」，chip 已切但列表仍是「全部」的结果，无任何提示 | 数据记录所属查询条件；换条件失败走全屏错误态，同条件刷新失败保留内容 + 错误条（PR #29） |
