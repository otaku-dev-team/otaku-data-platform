### 6.4 阶段 2 · 同账号跨端管理（后端就绪，待联调）

- **目标**：同一账号在两端看到一致的个人收藏与观看状态。
- **任务**：后端账号 / 多设备会话 / 收藏（已完成）；openapi 阶段 2（已完成）；客户端登录 / 收藏 / 令牌 / 401 兜底 + **接真实接口（PR #44 已合并）** + 遗留三项补回（PR #57）；**联调演示待执行**。
- **验收口径（C1–C11）**：
  1. A 同时登录手机与电脑，两端会话均有效；
  2. 手机收藏并设「想看」→ 电脑刷新可见；
  3. 电脑改「看过」→ 手机刷新显示「看过」；
  4. 一端取消收藏 → 另一端刷新后该条与状态消失；
  5. B 看不到 A 的收藏；A 退出切 B 后不展示 A 的缓存；
  6. 失败不显示「已同步」；两端同时修改按服务端提交顺序（LWW）；
  7. 退出手机后电脑仍可用；手机重登后数据保留。
- **不依赖全量导入**：A/B 账号 + 现有 10,001 条即可覆盖。
